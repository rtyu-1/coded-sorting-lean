# 定义展开所用的基础概念

项目定义最终使用 Lean 和 Mathlib 中的数学对象。本页解释逐层展开项目定义后会遇到的基础记号；项目自己的名称继续由[定义索引](DefinitionIndex.zh-CN.md)展开。

| 记号或基础类型 | 数学含义 |
| --- | --- |
| `ℕ`、`Nat` | 非负整数；自然数减法在结果为负时取 0 |
| `ℚ`、`ℝ` | 有理数、实数；复杂度不等式在实数中计算 |
| `Fin n` | 小于 $n$ 的自然数，附带范围证明 |
| `Fin n → α` | 长度为 $n$、每项属于 $\alpha$ 的数组 |
| `α × β` | 同时包含一个 $\alpha$ 值和一个 $\beta$ 值的有序对 |
| `α ⊕ β` | 带左右标记的两类值；用于区分不重叠的存储区 |
| `Option α` | `none` 或 `some a`；在程序选择下一步操作时，分别表示停止或给出下一条指令 |
| `List α`、`Array α` | 有限序列；列表按空表和首项加尾表递归定义，数组用下标访问 |
| `Fintype.card α` | 有限类型 $\alpha$ 的元素数量；用于数存储位置或地址 |
| `Function.update f i v` | 在位置 $i$ 取新值 $v$，在其他位置保留函数 $f$ 的值 |
| `Equiv`、`≃` | 两个集合间的双射，包含正反映射及互逆条件 |
| `Matrix I J α` | 函数 `I → J → α`，即每个行列下标对应一个矩阵元素 |
| `ZMod n` | 模 $n$ 的整数；地址变换按相应环上的加法和乘法计算 |
| `Submodule`、正交补、投影 | 线性子空间及其线性代数关系，用于描述固定电路的矩阵标签 |

## 条件和量词

`∀ x, P x` 要求每个 $x$ 都满足 $P$；`∃ x, P x` 给出一个满足 $P$ 的 $x$。量词顺序决定依赖关系：`∃ K, ∀ N, ...` 给出所有 $N$ 共用的 $K$。主定理中的程序也先由规模参数确定，再对任意输入执行。

`A ∧ B` 要求两项都成立；`A ∨ B` 要求至少一项成立；`A → B` 是在条件 $A$ 下证明 $B$。`Prop` 中的项是数学命题，条件的证明用于 Lean 核验。

## 排列与有序

`List.Perm xs ys` 是由空表、两边加相同首元素、交换相邻首元素及传递规则生成的关系；它保留列表长度、每个值及其重复次数。

`List.Pairwise R xs` 的递归含义是：首元素与尾表中每个元素满足 $R$，尾表也满足同一条件。取 $R=(\le)$ 就是非降序排列。

## 数值运算与取整

自然数中的 `/` 是向下取整的除法，`%` 是余数。`Nat.clog b n` 是以整数基数 $b$ 表示 $n$ 所需的上取整对数；本项目在使用处给出相应的正性和基数条件。`⌈κ⌉₊` 是不小于 $\kappa$ 的最小自然数。

`(N : ℝ)` 将自然数嵌入实数；`(N : ℝ)/B` 先转换再做实数除法。`Real.log` 是自然对数，实数幂用于 $1-\varepsilon$ 等非整数指数。主复杂度公式满足 $M/B\ge2$、$M\ge2$，所以分母中的对数为正。

## 固定选择、结构字段和递归

`Classical.choose h` 从存在性命题 `h` 中选取一个对象；`Classical.choose_spec h` 给出它满足的性质。判断一个被选取的系数是否固定，要阅读 `h` 的完整量词次序及参数。

`.mk` 按字段次序把各部分数据组成一个结构值；用字段名就能读回其中某一项，例如 `s.disk` 读取状态 `s` 中的磁盘内容。Lean 自动生成的 `casesOn`、`recOn`、`match_...` 根据构造方式分支或递归。自动索引保留这些声明，并链接回产生它们的源码定义。

执行关系的规则说明单步怎样改变状态，以及前后两段执行怎样连接。有限次使用这些规则，就得到从初始状态到最终状态的有限执行过程。`run` 的自然数参数指定观察的步数；程序停止条件则由具体状态转移定义决定。
